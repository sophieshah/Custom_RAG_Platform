TB COMMUNITY ISOLATION RULE ENGINE v0.2.0
Updated 15 October 2026 to implement the user's revised policy and anchor table.

QUICK START
Python 3.10+, standard library only.
  python tb_isolation_rules.py example_input.json
  python -m unittest -v test_tb_isolation_rules.py

In an application:
  from tb_isolation_rules import evaluate
  result = evaluate({
      "bacterial_burden": "low",
      "community_risk": "low",
      "gxp_status": "rif_sensitive",
      "treatment_days": 5
  })

These four inputs produce:
  restriction_level: "no restriction"
  expected_days_of_restrictions: 5
  expected_remaining_days: 0
with every assumed input disclosed in assumptions and explanation.

WHAT CHANGED
1. Setting and respiratory_tb are optional context, not mandatory scope gates.
   Missing setting no longer produces an out-of-scope error or extensive restriction.
2. Missing optional data no longer become high burden/high risk or treatment failure.
3. Resistance concern defaults to no; harm to moderate; adherence and tolerability
   to yes; clinical response to improving. All are labeled assumptions, never
   reported as verified clinical observations.
4. RIF-sensitive + no concerns can establish assumed treatment effectiveness.
5. Missing burden/community grades are inferred when possible or returned as
   questions, never silently assigned high.
6. Durations now implement the user's October 15 anchor table, including the
   1d versus 5b distinction and the immunosuppressed 5c pattern.
7. Removed the blanket vulnerable-contact 14-day rule and the blanket requirement
   for expert signoff simply because isolation has already lasted over 14 days.
8. Explicit no-improvement, rising smear, poor adherence, intolerance, or resistance
   override favorable assumptions. Unchanged smear at >=14 days prompts review.

PRIMARY OUTPUT CONTRACT
restriction_level:
  "no restriction", "moderate restriction", or "extensive restriction".
  Only when a core grade cannot be inferred, or evidence conflicts, this is null
  and decision_status="needs_input". Display the required question; never map null
  to extensive. An invented clinical recommendation is not a missing-data fallback.
expected_days_of_restrictions:
  Selected total treatment-based target, e.g., 5, 7, 10, or 14. Zero for exemptions.
  This is not days still remaining, and excludes an unknown pretreatment interval.
expected_days_range:
  Preserves a user-supplied 5-10 or 10-14 anchor range. Favorable/default response
  chooses its lower end; explicit adverse response selects the upper planning end
  and requires review. Unlisted combinations use the interpolation table below.
expected_remaining_days:
  target minus credited effective days, floored at zero, only if no release blockers.
  Null when effectiveness, duration, response, or a necessary review remains unresolved.
credited_effective_treatment_days:
  Zero if treatment status/duration or effectiveness cannot be established.
assumptions / explanation:
  Every default and inferred treatment-credit assumption, suitable for LLM explanation.
questions:
  Short follow-up questions, with required_for_final_recommendation. Optional
  confirmations do not prevent a recommendation under the requested assumptions.
release_blockers:
  Explicit facts or unresolved treatment/review conditions that prevent release.
expert_consultation_recommended:
  A referral flag; it is not itself an automatic increase in isolation duration.

When a patient has adverse response or resistant TB, expected_days_of_restrictions
is the baseline target, NOT a promise of release. Additional time is unresolved;
expected_remaining_days stays null pending reassessment. All expected durations
are conditional on the stated assumptions, particularly drug regimen effectiveness.

INPUTS FOR A SIMPLE FORM
bacterial_burden: low / medium (or moderate) / high / unknown.
  Alternatively provide sputum_smear, cough, cavity.
gxp_status: rif_sensitive / rif_resistant / unavailable / not_detected / unknown.
  Display strings "detected RIF sensitive" and "detected RIF resistant" also parse.
drug_resistance_concern: yes / no / unknown, or Boolean. Default no with explanation.
community_risk: low / medium / high / unknown.
patient_harm: low / medium / high / unknown. Default medium if no domain grades.
treatment_days: completed treatment days; zero is distinct from null/unknown.
treatment_effective: yes / no / unknown, or Boolean. See inference below.

OPTIONAL MODIFIERS
adherent, tolerating, clinical_response, micro_response,
vulnerable_contacts, congregate_or_shelter, patient_immunosuppressed,
symptoms_resolved, age_years, adult_type_disease, harm-domain grades,
prospective exposure details, jurisdiction and explicit local-policy minimum.
Full canonical and legacy fields are in input_schema.json. Prefer the small form;
do not force users to complete the compatibility fields. minimal_input_schema.json
contains the compact form, including the modifiers needed for special anchors.

Input spelling errors and conflicting aliases raise ValueError. Surface validation
errors as correction requests; never catch errors and default to extensive.
Explicit negative facts are never replaced with favorable defaults. Unknown/null
optional fields receive the requested defaults and remain identifiable as assumed.

BURDEN INFERENCE FROM PARTIAL DATA
Explicit burden grade is accepted without requiring all raw fields.
If no grade is supplied:
  - Smear 2+/3+/4+ or cavity present -> high.
  - Smear scanty/1+/positive without grade, or frequent cough -> moderate.
  - Smear negative without a known cavity or frequent cough -> provisional low.
  - No cavity and no cough -> provisional low even if smear is unknown.
  - Otherwise ask for a burden grade or additional findings.
Missing markers remain unknown, not converted into negative test results. Partial
inferences are identified and a confirmation question is returned. A directly
supplied low/moderate grade conflicting with a high smear/cavity asks for resolution.
This is a practical triage mapping, not a validated burden score. GXP positivity
or extrapulmonary bacterial burden alone does not assign respiratory burden.

COMMUNITY RISK
Accept the structured grade. If absent, use prospective exposure information:
  - Vulnerable contacts, congregate/shelter return, or recurrent/prolonged exposure
    in poor ventilation -> high.
  - No new contacts, or few brief contacts outdoors/well ventilated -> low.
  - Other known contact number/frequency/environment combinations -> moderate.
  - Otherwise ask for the grade.
Known prospective vulnerable/congregate exposure raises a lower direct grade.
"Vulnerable" here is very young or immunocompromised exposed contacts, not the
patient's own immunosuppression. Do not double-count treatment by feeding an already
treatment-adjusted risk score into this independent community dimension.

HARM
Use the highest reported overall or domain grade across housing, finances, food,
employment, mental health, stigma, and access to care. Missing domains do not block
the available grade. If all grades are absent, assume moderate and disclose it.

TREATMENT AND RESISTANCE
- A positive treatment-day count establishes treatment has started when the status
  field is absent/unknown. If both start and duration are unknown, use zero credit.
- If explicitly not on treatment but positive days are supplied, ask to resolve it.
- RIF-sensitive and no resistance concern -> assume effectiveness when adherence,
  tolerance and clinical improvement are favorable or their disclosed defaults apply.
- Explicit effectiveness=yes can support unknown-GXP or resistant regimens; this
  represents the clinician's assessment of the actual regimen, not the engine's
  inference. Resistant cases also use the expert-review pathway.
- Alternatively, adequate regimen + supportive laboratory evidence can establish
  effectiveness, with resistance addressed if present.
- Unknown/unavailable GXP with effectiveness unknown does not establish effectiveness.
  Ask the question, give zero credit, and show a 10/14-day conditional target.
  A patient already on treatment ordinarily receives moderate restrictions while
  this is clarified; absent GXP is not automatically extensive.
- Reported resistance overrides the default no-concern assumption. RIF-sensitive
  does not exclude INH/PZA/other resistance or clinical/epidemiologic suspicion.
- Explicit poor adherence, intolerance, ineffectiveness, or unexplained clinical
  nonresponse/rising smear prevents treatment credit. A reviewed alternative
  explanation can resolve a response concern, not poor adherence or intolerance.
- Reported treatment days are assumed continuously effective under the stated
  effectiveness assessment. If not all days were effective, supply
  uninterrupted_effective_days separately. It cannot exceed treatment_days.
- Do not infer an effective-treatment clock from days since diagnosis or isolation.

USER ANCHOR POLICY (TOTAL DAYS)
RIF-sensitive, no unresolved resistance concern:
  Low burden, low community risk: 5 (2a, 2c).
  Low burden, high community risk: 10 (2b, 2d).
  Low burden, high risk, vulnerable contacts, LOW harm: 14 (5d).
  Moderate burden, low risk: 7 (1a; also interpolation for higher harm).
  Moderate burden, immunosuppressed patient, low risk: 10, conditional on symptom
    resolution (5c). If explicitly not resolved but improving, reassess at 14.
    Unknown resolution at day 10 prompts confirmation. Continued improvement at
    day 14 does not automatically extend isolation beyond 14 solely for symptoms.
  High burden, low risk, low harm: 10-14, default planning target 10 (6c).
  High burden, low risk, moderate/high harm: 5-10, default target 5 (1c).
  High burden, high risk, low harm: 14 (1b, 5a).
  High burden, high risk, moderate/high harm: 10 (1d), 14 for congregate/shelter (5b).
  High community risk with congregate return: 14, including lower-burden cases.

No available GXP RIF-sensitive result:
  Low burden + low community risk: 10 (4a, 4c).
  All other graded combinations: 14 (4b, 4d, 3a-3d, 6b; intermediate combinations
    are an explicit conservative interpolation).
  No-GXP floor remains even if other lab information supports effectiveness.

Unlisted medium-community combinations (explicit policy interpolation):
  Low burden: 7.
  Moderate burden: 10.
  High burden: 14 with low harm; 10 with moderate/high harm.
Higher harm uses the moderate-harm branch, never overrides treatment failure.
Only low-burden/low-risk/RIF-S or high-burden/low-risk with moderate/high harm uses 5.

EXEMPTIONS
Child under 10, low burden (or explicit noninfectious pediatric assessment),
adult_type_disease=no and no reported positive sputum/cavity -> no restriction, 0.
This does not require cough, extensive-CXR, GXP, setting, and adherence fields all
to be completed. Known sputum positivity/cavity prevents this exemption. If the
adult-type phenotype is unknown, the exemption is not automatically applied.
Explicit respiratory involvement excluded also gives no community RIR, unless
respiratory findings conflict. A negative GXP alone is not an exclusion of TB.

LEVEL WHILE THE TARGET HAS NOT BEEN MET
Before treatment or with explicitly ineffective/problematic treatment:
  Extensive, except low burden + low community risk can use moderate.
On treatment:
  Ordinarily moderate; missing feasibility, tolerance, adherence, setting, or other
  optional fields do not independently force extensive.
  Extensive for unresolved resistant therapy, resistant effective therapy <5 days,
  or explicit inability to implement targeted restrictions with high community risk.
No restrictions once the selected target and necessary conditions are met.
Moderate restrictions still exclude the relevant high-risk exposure; they do not
automatically authorize daycare, congregate, or healthcare return.

BEYOND 14 DAYS AND WASHINGTON
Routine drug-susceptible targets cap at 14. Declining smear positivity never extends
the duration. No smear conversion requirement is encoded.
Clinical nonresponse, rising smear, unchanged smear at/after 14 days, adherence
problems, or suspected resistance prompt expert review; the engine does not invent
a fixed extra number of days. Unchanged smear earlier in treatment alone is not
an indefinite-isolation rule. An explicitly reviewed nonfailure explanation can
resolve the trajectory concern.
The prior conservative resistant-TB pathway retains a 14-day planning minimum
plus explicit effectiveness and expert review; 20/21/24 calendar-day case outcomes
are not universal regimen-specific minimums. This is a program-policy choice.
Documented extenuating circumstances may use individualized_minimum_days with a
reason. They can extend but not shorten the calculated target.
Washington is handled by an explicit local-policy minimum and policy reference,
or a local-review question. No universal Washington duration is invented. The
official Washington manual remains the source for actual jurisdictional criteria:
https://doh.wa.gov/you-and-your-family/illness-and-disease-z/tuberculosis-tb/public-health-professionals/tb-services-manual

EVIDENCE AND POLICY STATUS
The October 15 user-supplied anchor table and defaults control this revision.
Its fixed days and assumptions are implementation policy, not all universal NTCA
requirements. Existing casebook/spreadsheets informed v1; v2 reconciles their
ambiguities using the user's explicit instructions rather than copying old AI outputs.
The general NTCA reference was checked online during this revision:
https://www.idsociety.org/practice-guideline/ntca-tb-guideline/
https://doi.org/10.1093/cid/ciae199
NTCA supports effective treatment as central and individualized community decisions.
This code has software tests, not prospective clinical validation. It does not
prescribe a regimen or grant hospital airborne-precaution clearance.

MIGRATION AND TESTING
Existing parse_inputs()/Inputs()/evaluate() entry points and legacy input names
remain. isolation_level (none/moderate/extensive) and duration compatibility keys
remain alongside the new requested labels. evaluate() now also accepts a dictionary.
The old Policy parameter was removed; the rules are the explicit October 15 policy.
Callers using evaluate(inputs, custom_policy) must migrate to the new policy module.
Do not suppress needs_input by substituting extensive.
anchor_validation.json records all supplied anchor rows (expanded for harm variants).
case_reconciliation.json updates the 25 standardized target comparisons, without
claiming that historical resistant-TB calendar courses equal effective days.
The suite exercises missing inputs, defaults, adverse overrides, day boundaries,
child exemptions, local policy, all anchors, and 576 graded combinations.
